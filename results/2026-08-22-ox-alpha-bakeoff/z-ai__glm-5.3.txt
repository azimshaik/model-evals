```python
def is_valid_isbn10(code: str) -> bool:
    if not isinstance(code, str):
        return False
    digits = code.replace('-', '')
    if len(digits) != 10:
        return False
    total = 0
    for i, ch in enumerate(digits):
        if '0' <= ch <= '9':
            value = ord(ch) - ord('0')
        elif i == 9 and ch in ('X', 'x'):
            value = 10
        else:
            return False
        total += value * (10 - i)
    return total % 11 == 0
```

Using explicit '0' <= ch <= '9' avoids Unicode digit acceptance.

Explanation paragraph: The checksum computes sum of each digit multiplied by a weight from 10 down to 1; the check digit is chosen so the total is a multiple of 11. Because 11 is prime and the weights are all distinct and non-zero modulo 11, swapping two adjacent digits changes the sum by (a−b)(w_i − w_j) which is non-zero mod 11 when a≠b, so any single transposition breaks divisibility; likewise any single-digit error is caught because weights are non-zero mod 11.
